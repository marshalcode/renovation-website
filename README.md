# RM BAU Website

Website for a renovation and construction company in the Rhein-Main area.

## Status

The website is currently under development.

Implemented so far:

- responsive hero and navigation
- company benefits
- services section
- project call-to-action
- project process
- about section
- footer
- mobile responsive layout

The projects, customer reviews, contact form, legal pages and final content will be added in the next steps.

## Tech Stack

- HTML
- CSS
- JavaScript
- PHP planned for the contact form

No frontend framework or build system is used.

## Local Development

Run the website locally from the project root:

```bash
python3 -m http.server 8000 --directory public
```

Then open:

```bash
http://localhost:8000
```
