Datenschutzerklärung

Diese Website befindet sich derzeit im Aufbau. Nachfolgend informieren wir über die derzeit eingesetzten externen Dienste und die damit verbundene Verarbeitung personenbezogener Daten.

1. Hosting über GitHub Pages

Diese Website wird derzeit über GitHub Pages, einen Dienst der GitHub, Inc., USA, bereitgestellt.

Beim Besuch dieser Website werden technisch notwendige Verbindungsdaten verarbeitet. Nach Angaben von GitHub werden insbesondere IP-Adressen der Besucher zu Sicherheitszwecken protokolliert und gespeichert.

Weitere Informationen zur Datenverarbeitung durch GitHub finden Sie in der Datenschutzerklärung von GitHub .

2. Google Fonts

Diese Website verwendet Google Fonts zur einheitlichen Darstellung von Schriftarten. Die Schriftarten werden derzeit über Server von Google geladen.

Beim Aufruf der Website stellt der Browser eine Verbindung zu den Servern von Google her. Dabei kann insbesondere die IP-Adresse des Besuchers an Google übermittelt werden.

Weitere Informationen finden Sie in der Datenschutzerklärung von Google .

3. Aktueller Entwicklungsstand

Die Website befindet sich derzeit in der Entwicklung. Das vorhandene Anfrageformular ist noch nicht für die Übermittlung von Anfragen freigeschaltet.

Bei der Einführung weiterer Funktionen oder Dienste werden diese Datenschutzhinweise entsprechend aktualisiert.
